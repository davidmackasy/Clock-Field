DEV NOTE: Revise Scheduled Notes Template Builder Into Main Step Groups With Multiple Required Photos
Project: Clockfield
Area: Work Log → Scheduled Notes
Feature: Scheduled Field Notes
Main goal:
Change the Scheduled Notes template builder mindset.
Instead of creating a main step first, then manually adding many sub-steps one by one inside it, the admin should create one complete main step group at a time.
A main step group represents one area or room.
Example:
Main Step Group: Women’s Washroom
Included items: Sink, Mirror, Toilet, Floor, Dispenser
Reference photos: 5 to 8 photos uploaded at once
Then cleaner sees that group as one cleaning photo set, with each reference photo becoming one required photo task.
Do not break or affect anything currently working.
Do not change regular Field Notes.
Do not change normal Work Log.
Do not change clock-in, clock-out, attendance, payroll, clients, auth, Stripe, or public regular Field Notes.
Only update Scheduled Notes.
Ask for approval before touching anything outside this module.

1. Current Problem
Current flow:
Admin creates template.
Admin clicks Add Main Step.
Admin types a main step name.
Then admin has to go inside that main step and add sub-steps one by one.
This is too slow and confusing.
For a large building, admin might need:
20 offices
3 washrooms
Kitchen
Hallway
Lobby
Storage room
Each area may need 4 to 8 photos.
The current flow becomes too much clicking.

15. Assignment Must Connect To Existing Schedule
Important new requirement:
When assigning a template to a cleaner, admin must also select the cleaner’s schedule.
Assignment flow should include:
Template
Cleaner
Location
Schedule
Required before clock-out
Active days / frequency if needed
The schedule must come from the existing Schedule system.
Do not create a new schedule system.
Use the existing schedule records.
When admin selects a cleaner:
Show that cleaner’s available schedules.
Admin selects the schedule this Scheduled Note applies to.
Example:
Cleaner: David Mackasy
Schedule:
MackasyInc - Monday to Friday - 6:00 PM to 10:00 PM
Assignment rule:
This Scheduled Note is required when the cleaner clocks in for that selected schedule.
Do not trigger it for unrelated clock-ins.

16. Clock-In / Clock-Out Connection
Scheduled Notes should activate based on the selected assignment schedule.
When cleaner clocks in:
Check:
Is this cleaner assigned to a Scheduled Note?
Is the Scheduled Note active?
Is this clock-in connected to the selected schedule?
Is today a valid scheduled day?
If yes:
Show required Scheduled Note task.
If required before clock-out:
Cleaner cannot clock out until required photos are completed.
If cleaner clocks in for a different schedule:
Do not show this Scheduled Note.
Do not block clock-out.
This prevents wrong Scheduled Notes from showing at the wrong job.
