1. Main problem with current quote form

Right now the quote form is too manual.
It asks for too many raw inputs too early.
It does not adapt based on building type.
It does not guide the user.
It does not suggest pricing strongly enough.
It does not separate internal pricing inputs from client-facing quote output.

We need to turn this into a smarter quote assistant.

2. New quote flow structure

When user clicks Turn into Quote from a Field Note, the system should not immediately show one generic static form.

It should become a guided quote builder with these steps:

Step 1
Property type selection

Step 2
Dynamic property details based on selected type

Step 3
Service scope inputs

Step 4
Internal pricing inputs

Step 5
AI pricing suggestion

Step 6
Client-facing quote preview

Keep the UI compact and smooth.
Do not overcrowd the page.
Do not make it look heavy.

12. AI image condition analysis

Since this starts from a Field Note, the system should use the existing Field Note photos to help determine condition.

Examples

If kitchen photos show grease, residue, stains, buildup:
increase difficulty factor

If washrooms show visible heavy use:
increase condition factor

If office looks lightly dusty only:
lower difficulty factor

If industrial area shows heavy debris:
increase labor estimate

Important

This image analysis should help the suggestion.
It should not silently overwrite user-entered data.
User can still edit or override the suggestion.

Detailed scope summary
Optional recommended plan

Example logic

For office:
Routine cleaning of offices, washrooms, hallways, reception area, and break room with focus on floor care, garbage removal, surface wiping, and restroom sanitation.

For restaurant:
Cleaning of kitchen, prep areas, counters, dining area, washrooms, and flooring with extra attention to grease-prone surfaces and food-service sanitation points.

For industrial:
Cleaning of office areas, washrooms, lunch room, entrances, and designated production-adjacent spaces with attention to debris, floor buildup, and high-use zones.
