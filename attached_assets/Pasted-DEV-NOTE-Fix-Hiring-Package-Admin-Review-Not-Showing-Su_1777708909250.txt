The public Hiring Package flow is being completed successfully. The applicant accepts policies, fills personal information, emergency contacts, medical info, uploads documents, signs, and submits. The public link then shows Under Review.

Root Problem To Check


The public page shows Under Review, so submit status is being saved somewhere.
But the admin Review modal is not reading the same submitted data.
Check for these likely issues:
Public flow saves data in one table, admin review reads another table.
Public flow saves under token, admin review fetches by package ID but does not join submission data.
Public flow stores data in local state or localStorage but not database.
Public flow saves submitted status only, not the full submission payload.
Admin review uses stale package data instead of submission data.
Admin review expects fields under different names than public flow saves.

Signature is stored under signatureStorageKey but admin review expects signature_url.
Final acknowledgement is stored as boolean but admin review expects string or different key.
Uploaded document keys mismatch.
