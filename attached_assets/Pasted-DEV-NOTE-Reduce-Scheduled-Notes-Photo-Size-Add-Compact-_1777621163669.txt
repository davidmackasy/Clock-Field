DEV NOTE: Reduce Scheduled Notes Photo Size, Add Compact Grids, Improve Main Steps / Sub-Steps, Keep 9:16 Only On Click
Project: Clockfield
Area: Work Log → Scheduled Notes
Feature: Scheduled Field Notes
Main goal:
The Scheduled Notes feature is working better now, but the photo cards are too large. This will not work when a cleaning company has large locations with 20 offices, 3 washrooms, 100+ checklist photos, and daily submissions.
We need to make the admin template builder, submission detail view, and final report much more compact.
Do not break or affect anything currently working.
Do not change regular Field Notes.
Do not change Work Log outside Scheduled Notes.
Do not change clock-in, clock-out, payroll, attendance, clients, auth, Stripe, or existing public Field Notes.
Only improve Scheduled Notes layout, step structure, dropdowns, and photo display.

1. Main UI Problem
Right now, the image cards are too big.
The reference photos are being displayed like large 9:16 cards directly inside the page.
That is not what we need.
Important rule:
9:16 should only apply when the user clicks the image and opens the full preview modal.
The normal template view, submission view, and report view should use small compact thumbnails.
Default thumbnail ratio should be:
1:1 square
or compact horizontal card if needed
The page view should not show giant vertical images.

2. New Photo Display Rule
Use this rule everywhere inside Scheduled Notes:
Normal page view:
Small 1:1 thumbnail
Compact card
Grid layout
Many photos visible at once
Click preview:
Open image in modal
Show full 9:16 image preview
Allow zoom / larger view if existing modal supports it
Use object-fit: cover for thumbnails.
Use object-fit: contain for the full modal preview.
Do not stretch images.
Do not crop the modal preview.

3. Template Builder Must Be Compact
Current problem:
The template builder shows big cards.
A template with 50 to 100 steps will become impossible to manage.
Required improvement:
Inside each section, show sub-step cards in a compact grid.
Desktop:
10 cards per row if screen width allows.
Large desktop:
10 to 12 cards per row.
Medium screens:
6 to 8 cards per row.
Tablet:
4 cards per row.
Mobile:
2 cards per row.
Each step card should be small.
Example card size:
Width: around 96px to 120px
Image: square 1:1
Text: max 1 to 2 lines
Use ellipsis for long titles.
Do not show long instructions on the card.
Show instructions only when editing or opening detail.
