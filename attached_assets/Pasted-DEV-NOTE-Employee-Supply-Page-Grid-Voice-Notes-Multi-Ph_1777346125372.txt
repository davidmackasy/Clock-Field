DEV NOTE: Employee Supply Page Grid, Voice Notes, Multi-Photo Supply Reports, and Admin Response Notifications

Project: Clockfield
Area: Supplies / Supply Requests / Employee App / Admin App
Goal: Improve the supply reporting flow without changing or breaking anything else that is already working.

Important instruction:
Do not break, remove, rename, or change any existing working supply, request, location, inventory, employee, admin, notification, or photo upload logic unless it is directly required for this task.

Do not touch unrelated pages.

Do not change authentication.

Do not change payroll.

Do not change schedule.

Do not change attendance.

Do not change field notes.

Do not change reports.

Only update the employee supply reporting flow and the related admin supply review/response flow.

Current Issue

On the employee side, the Supplies page currently shows supply items in a 2-column grid.

The requested change is:

Employee supply items should show in a 3-column grid where screen width allows it.

When the cleaner taps a supply item, the popup should allow:

Issue/status selection

Short description

Voice-to-text input for the description

1 to 3 uploaded/taken photos

Submission to admin

The original supply product image must stay the same. Cleaner-submitted photos must be attached only to the submitted update/report.

The admin must be able to view the cleaner’s submitted report, including all attached photos.

The admin must be able to respond/update the supply request.

The cleaner must receive a visible alert/notification when the admin responds or updates that item.

Required Changes

1. Employee Supplies Grid

Update the employee Supplies page layout.

Current behavior:
Supply cards show in rows of 2.

Required behavior:
Show supply cards in a 3-column grid where space allows.

Use responsive behavior:

Mobile small screens:
Use 2 columns only if 3 columns becomes too cramped.

Normal mobile width shown in the screenshot:
Use 3 columns.

Tablet:
Use 3 or 4 columns depending on available width.

Desktop:
Use 4 or more if the current admin/employee layout supports it.

Make sure each card still shows:

Supply image

Supply name

Category/location

Status badge

Assigned quantity

The card must remain clickable.

Do not crop images badly.

Do not stretch product images.

Use object-contain for product images.

Keep the UI clean and professional.

3. Voice-to-Text Description

Add a mic button inside or beside the description field.

Cleaner flow:

Cleaner taps mic icon.

Cleaner speaks the issue.

The app transcribes the voice into text.

After transcription, clean up the grammar.

Insert the polished text into the description field.

Example:

Spoken:
“the cleaner is almost finished only small left bottle leaking too”

Final text:
“The cleaner is almost finished. There is only a small amount left, and the bottle is leaking.”

Requirements:

The cleaner must be able to edit the text manually after transcription.

Show recording state clearly.

Example:

Mic button changes to “Listening…”

Show stop button if needed.

Handle permission errors properly.

If mic permission is blocked, show a friendly message:
“Microphone access is blocked. Please allow microphone access or type your note manually.”

Do not block manual typing.

Recommended implementation:

Use browser SpeechRecognition if already available in the app.

If the app already uses OpenAI/GPT transcription anywhere else, reuse the existing safe pattern.

After transcription, send the raw transcript to the backend for grammar cleanup using the existing AI utility if available.

Do not expose API keys on the frontend.

Do not create a new AI provider if the project already has one.

Suggested backend endpoint:

POST /api/supplies/grammarize-note

Request:

{
"rawText": "the product is almost done bottle leaking"
}

Response:

{
"cleanText": "The product is almost finished, and the bottle is leaking."
}

If AI cleanup fails, keep the raw transcript and allow the cleaner to submit.

4. Allow 1 to 3 Photos Per Supply Update

Update the photo section in the supply report modal.

Current behavior:
Photo is optional and likely supports one image.

Required behavior:
Cleaner can attach up to 3 photos.

Cleaner can attach:

1 photo

2 photos

3 photos

No photos only if current logic allows optional photos. Do not force photos unless the app already requires them.

The UI should show:

Take / Upload Photo button

Preview thumbnails

Remove button on each selected photo

Counter:
“0/3 photos added”
“1/3 photos added”
“2/3 photos added”
“3/3 photos added”

When 3 photos are added, disable the upload button or show:
“Maximum 3 photos reached.”

Accepted sources:

Camera capture

File upload

Mobile camera upload

Important:

The cleaner-submitted photos must be stored as report/update attachments.

They must not replace the original product image shown on the supply card.

The supply product image must remain unchanged on both employee and admin sides.

5. Submit Supply Update Payload

When the cleaner submits the update, send:

Supply item ID

Location ID

Employee ID

Report status

Cleaned/grammarized description

Submitted photo URLs or uploaded photo files

Timestamp

Current assigned quantity if needed

Company/business ID if needed for multi-tenant filtering

Example payload:

{
"supplyItemId": "abc123",
"locationId": "location123",
"employeeId": "employee123",
"status": "Out of Stock",
"description": "The CP Cleaner is almost finished, and the dispenser area needs replacement soon.",
"photos": [
"photo-url-1",
"photo-url-2",
"photo-url-3"
],
"submittedAt": "timestamp"
}

Make sure this creates a new supply report/update record.

Do not overwrite the supply item.

Do not overwrite the product image.

Do not overwrite the assigned inventory data unless the current app already does that intentionally.
