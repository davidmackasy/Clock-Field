DEV NOTE: Add Agreements & E-Signature System under Proposals (No Breakage)

Goal
Add a full Agreements system inside Clockfield that allows admins to generate, send, and collect legally structured agreement signatures tied to quotes.

This must integrate with Proposals / Quotes and Publications without breaking existing functionality.

Do not modify or remove the current Publication system.
Do not change existing quote flows.
This is an additive layer.

FEATURE PLACEMENT

Primary location:

Proposals / Quotes → Add new tab or section:

Agreements

Also allow access from:

Inside each Quote (Generate Agreement button)
Optional view under Publications as a new type:
“Agreement Publication” (separate from blog-style publications)
CORE FLOW

Admin flow:

Create or open a quote
Click “Generate Agreement”
Agreement auto-generates using quote data
Admin edits or confirms agreement
Send agreement via email or link
Client opens link
Client reviews agreement
Client signs digitally
Optional witness signs
Agreement status updates in real time
Admin receives notification
Agreement is stored and downloadable as PDF
