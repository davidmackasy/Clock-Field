DEV NOTE: Improve Training Hub Lesson Blocks + Premium Audio

Scope:
Only update Training Hub lesson/module content system.
Do not affect anything else in ClockField.

Goal:
Make modules more visual, structured, and engaging instead of showing one long boring text block.

AI Course Generator Update

When AI generates modules, it should generate lesson blocks.

AI output should include:

module title
module intro
videoUrl empty field
blocks array

Each block should have:

type
title
content
imagePrompt optional
caption optional
checklist optional

Example:

blocks: [
{
type: "text",
title: "What workplace hazards mean",
content: "..."
},
{
type: "image_prompt",
title: "Example hazard image",
imagePrompt: "A wet floor sign near a washroom entrance"
},
{
type: "checklist",
title: "Hazard inspection checklist",
checklist: [...]
}
]

Important:
AI should suggest where images should go.
Admin can upload real images later.

Premium Text-to-Audio

Current browser voice sounds robotic.

Add OpenAI TTS option for Training Hub module audio.

Behavior:

If OpenAI TTS is configured:
Use OpenAI premium voice audio.

If not configured:
Fallback to browser text-to-speech.

Audio should read the full module in order:

Module title
Block 1 text
Block 2 caption
Block 3 text
Checklist
Key takeaways

Controls:

Play
Pause
Stop
Speed:
0.75x
1x
1.25x
1.5x

Audio Caching

To control cost:

Generate audio only when user clicks “Generate Audio” or “Listen”
Cache audio URL per module version
Reuse cached audio unless module content changes

Do not regenerate every time user opens the course.

Do Not Break Existing Data

Keep old modules working.

Migration/fallback:

If old module has lesson_text only:
Render it as one text block automatically.

If new module has blocks:
Render blocks.

Do not delete existing lessons.

Expected Result

Admin can build modules with multiple lesson sections and images.
AI can create structured lesson blocks.
Employees see a more visual course.
Modules feel professional and easier to understand.
Audio sounds better using OpenAI TTS when available.
Nothing outside Training Hub is affected.
