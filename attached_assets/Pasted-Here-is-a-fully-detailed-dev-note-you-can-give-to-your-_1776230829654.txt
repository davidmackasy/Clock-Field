1. Rebuild Field Note generation pipeline for higher accuracy

Do not rely on raw transcript alone.

New pipeline should be:

Step 1
Capture clean transcript from audio with timestamps if possible.

Step 2
Extract photo timeline and associate each photo with capture time.

Step 3
Use GPT-5.4 to process transcript plus photo sequence together, not separately.

Step 4
Generate structured intermediate data first, not direct final prose.

Step 5
Generate final polished report from validated structured data.

This is very important.

Do not go directly from transcript to final note.

Instead use a two-pass or three-pass pipeline.

Recommended pipeline

Pass A. Evidence extraction
Input:
Full transcript
Photo metadata
Ordered photos
Optional session metadata like location, cleaner name, admin name, property, timestamp

Output as structured JSON:
visit_type
report_title
summary
sections[]
observations[]
issues[]
completed_work[]
recommended_actions[]
uncertain_items[]
photo_groups[]

Pass B. Validation and grounding
Use GPT-5.4 vision + transcript reasoning to validate whether the extracted section content is actually supported by the photos and transcript.
If unsupported, either remove it or mark it as uncertain internally.
Do not show hallucinated content to end users.

Pass C. Final report writing
Generate the clean client-facing report only from the validated structured JSON.

This should reduce made-up or mismatched statements.

2. Add stronger grounding rules

The model must not invent observations.
It must only state things that are supported by:
The transcript
The images
Or both

If the user says something but the photo is unclear, the system can still include it, but only if the transcript strongly supports it.

If the image shows something clearly but the transcript does not mention it, it can include it only if confidence is high.

If confidence is low, do not include it in the main report.

Internal confidence rules

High confidence
Mention freely in report

Medium confidence
Mention only in a softer way

Low confidence
Do not include in client-facing text

Example

Bad
“The hallway was cleaned thoroughly” when there is no proof

Better
“Hallway area was discussed during the walkthrough”

Best
Only include “Hallway cleaned” if transcript and/or image clearly support it
