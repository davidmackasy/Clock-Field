Dev Note: Add Optional Client Walkthrough Capture to Quote Request Forms
Goal:
Add an optional “Client Walkthrough” step inside Quote Request Forms so clients can take photos, record short voice notes, and submit visual context with their quote request.
This should use the same concept as Field Notes, but it must not break, rename, or change the existing Field Notes feature used by employees and admins.
This is a new Forms / Quote Requests feature only.
Do not change existing Field Notes behavior.
Do not change employee Field Notes.
Do not change admin Field Notes.
Do not change public Field Notes links.
Do not change existing worklogs.
Do not change payroll, reports, schedules, incidents, client reports, or any unrelated Clockfield feature.
Do not remove existing form fields.
Do not make all form fields required.
Do not break the current WordPress iframe embed flow.
Do not remove “Created using Clockfield” from embedded forms.
If anything outside Forms / Quote Requests, Submissions, or Estimator needs to be changed, stop and ask first.

1. Feature Summary
Add a new optional step before final submission:
Client Walkthrough
This step asks:
Would you like to add a quick walkthrough of your space?
Client options:
Yes, start walkthrough
No, skip and submit
If the client chooses yes, they can:
Take multiple photos
Record voice notes while taking photos
Pause or mute the mic
Stop the walkthrough
Review photos before submitting
Submit the form with the walkthrough attached
This should help cleaning companies see the property condition, important areas, and client concerns before creating a quote.

6. Voice Note Behavior
If the client allows microphone access:
Record audio while walkthrough is active.
If the client denies microphone access:
Continue photo capture without audio.
Show a small message:
Microphone is off. You can still take photos and submit your walkthrough.
Do not block the walkthrough if microphone permission is denied.
If the client turns mic off:
Stop recording new audio.
Keep photo capture working.
If the client turns mic back on:
Continue recording from that point if possible.
Save:
Audio file
Duration
Transcript if generated
Photo timestamps
Photo order

18. Privacy and Consent Text

19. Error Handling
If camera permission is denied:
Camera access is off. You can skip this step or upload photos manually.
If microphone permission is denied:
Microphone is off. You can still take photos.
If upload fails:
This photo could not upload. Please try again or remove it before submitting.
If AI processing fails:
Walkthrough saved. AI summary could not be generated.
Do not lose the form data if upload or AI fails.
