SECTION 1
Add “Additional Admin” Management

Goal
Allow the main admin to add additional admins who can help manage the company account.

These additional admins should have the same permissions as the primary admin.

This feature must follow the same login setup style already used for employees.

Requirements

Create a new section:

Admin Panel → Admin Management

Menu location
Admin sidebar or mobile nav should include:

Admins

Inside Admins page show:

Admin List Table

Columns:

Name

Email

Role

Status

Date Added

Actions

Actions:

Edit

Reset Password

Deactivate

Add Admin button

Admin Creation Flow

Only an existing admin can create another admin.

Fields required:

Full Name

Email

Temporary PIN (same method used for employee creation)

Phone (optional)

Behavior

When admin creates a new admin:

System generates login credentials

New admin receives email invite (if email service exists)
OR

Admin can copy login details manually

First Login Experience

When new admin logs in the first time:

Step 1
Login using:
Email + Temporary PIN

Step 2
Force password change

Step 3
Admin creates their own password

After that, they access the dashboard normally.

Permissions

All admins have identical access for now.

Do not implement complex permission systems yet.

Future roles can include:

Owner

Manager

Supervisor

But for now:

All admins = Full Access.

Database

Add new field to users table if necessary:

role

Values:
admin
employee
client

OR

If role already exists, extend it.

Example user object

id
name
email
password
role
company_id
created_at

SECTION 2
Client Login Accounts

Goal
Allow admins to create login accounts for their clients.

Clients will be able to:

View their jobs

Send requests

Upload photos

Report issues

This is a very important feature.

Admin Flow

Admin → Clients Page

Currently clients likely exist only as records.

Add new option:

Create Client Login

Client creation fields

Client Name

Email

Phone

Address

Temporary PIN

Checkbox option:

Enable Client Login

If enabled:
Create authentication record for the client.

First Login Flow

Client logs in with:

Email
Temporary PIN

System forces password creation.

Same flow as employee login.

Client Dashboard

Clients should NOT see admin or employee tools.

Client dashboard should be minimal.

Client Dashboard Features

View upcoming cleanings

Submit requests

Upload photos

View service history

Client Requests Feature

Clients should be able to submit issues.

Example request form:

Title
Description
Upload photos
Location (optional)

Examples:

“Kitchen floor not cleaned”

Client uploads picture.

Requests go to:

Admin → Requests Page

Mark request types:

Client Request
Employee Request

SECTION 3

Images help admins verify problems.

Requirements

Allow uploads:
jpg
jpeg
png

Max size
10MB

Store images safely in existing storage system.

Display inside request detail page.
