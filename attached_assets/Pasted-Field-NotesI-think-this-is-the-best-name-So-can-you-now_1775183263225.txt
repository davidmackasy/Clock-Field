DEVNOTE: BUILD NEW “FIELD NOTES” PAGE AND MOBILE FLOATING ENTRY FOR AI VOICE + PHOTO JOBSITE DOCUMENTATION

Project goal

Build a brand new page called Field Notes for the cleaning platform. This is a new feature for admins, planners, and cleaners to document site visits, walkthroughs, before-and-after observations, and work-log style photo records by speaking while taking pictures. The system must use GPT-5.4 to turn voice plus photos into organized field documentation. The output must be structured, searchable, grouped by project and date, and easy to review later. This should feel similar in concept to CompanyCam’s project feed, timelines, and AI walkthrough flow, where users can snap photos, talk through what they see, keep everything tied to the project, and generate shareable documentation from that field activity.

Critical instruction

Do not break anything.
Do not refactor unrelated pages.
Do not modify current attendance.
Do not modify payroll.
Do not modify current task workflow.
Do not modify the existing client report flow.
Do not replace current work-log submission logic.
Do not touch any active submission or public report feature unless a new adapter is required only to mirror data into Field Notes.
This work must be isolated as a new module, new routes, new tables, new services, and new UI surfaces.

Core idea

Field Notes is not chat.
Field Notes is not a note-taking page.
Field Notes is a project-based visual documentation hub.

The user should be able to:
open a project
start a live session
talk naturally
take photos while walking the site
stop the session
let AI organize everything into structured notes tied to those photos

The final result must be an organized project feed with:
photos
date
time
location
captured by
AI-organized notes
session summaries
cleaner submissions
optional premium public reports

CompanyCam’s public material confirms the main pattern we are using as inspiration: project-based photo organization, recent project feed updates, timelines and galleries, AI voice-based job documentation, and AI-generated shareable summaries and reports.
