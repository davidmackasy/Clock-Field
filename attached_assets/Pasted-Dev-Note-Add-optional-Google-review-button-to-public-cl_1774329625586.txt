Dev Note: Add optional Google review button to public client reports only

Objective

Add a second optional review option on public client report pages so clients can choose to:

Leave a review on Clockfield
Leave a review on Google

This must be implemented safely and in isolation.

This feature must only affect:

business admin settings
public client report review section

Do not break, change, remove, or refactor anything else.

Critical scope lock

You must not touch or modify anything outside this feature unless explicitly approved first.

Do not touch:

attendance
schedule
payroll

cleaner portal
business login

auth

public report permissions

review verification logic already used by Clockfield
employee accounts

report upload flow
report creation flow
client report rendering outside the review section
admin systems unrelated to business settings

If you discover anything that appears to require a change outside this exact scope, stop and ask for approval before proceeding.

Feature summary

Businesses already have a Clockfield review option on public reports.

We now want to add a second optional button for Google reviews.

If a business has added its Google review link in admin settings:

show both review options on the public report page

If a business has not added its Google review link:

show only the existing Clockfield review option

Clicking the Google review button must:

open the business’s saved Google review link in a new tab
not submit any data through Clockfield
not alter the existing Clockfield review process

Required end result

On the public report page review section, clients should see:

Leave a review on Clockfield
Leave a review on Google

But only show the Google button when that business has configured a valid Google review link in settings.

URL validation rules

When saving the Google review link:

must be a valid https URL
must not be empty if user is saving a value
trim leading and trailing spaces
preferably restrict to Google review-related URLs only
store exactly for that business only

Recommended validation behavior:

accept only https links
reject invalid or malformed URLs
reject non-Google domains if you want tighter validation
do not save javascript links or unsafe protocols

Recommended safer validation:

only allow hosts that match Google review/profile URLs
examples may include google.com or g.page related review links depending on what the business provides

If validation fails:

show a clean admin error message
do not save partial or broken data
