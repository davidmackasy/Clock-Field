Goal:
Add a full Supplies feature so admins can manage supplies by location, and cleaners can view and update supply status from their mobile app.

Main concept:

Admin has a dedicated Supplies page.
Supplies are organized by location.
Admin can create supplies with name, category, location, image, and status.
Cleaner has a new Supply section under Profile.
Cleaner can open supplies for their assigned location(s), view what exists, and send updates when an item is running low, empty, damaged, or needs replacement.
Cleaner can take a photo and add a note about the supply issue.
Admin can review updates, refill/replace the supply, upload an updated photo if needed, and mark it resolved.
Changes should reflect on both admin and cleaner sides.
Must be mobile friendly on both sides, especially cleaner side.
