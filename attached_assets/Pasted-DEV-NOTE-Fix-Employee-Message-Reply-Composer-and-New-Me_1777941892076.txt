Issue 1: Reply box must stay fixed at the bottom of the conversation

Current problem

On the employee message conversation page, the reply area moves when scrolling.

The reply area includes:

Photo attach button

Reply text box

Send button

This should not scroll up and down with the message list.

Required behavior

The conversation messages should scroll.

The reply composer should stay fixed/sticky above the bottom navigation.

When the employee scrolls up to read old messages, the reply box must stay in the same place.

When the employee scrolls down, the reply box must still stay in the same place.

The text box can grow slightly if the employee types a longer message, but the composer itself must remain attached to the bottom area.

The bottom navigation must not cover the reply composer.

The blue Action button must not overlap the reply composer.

Required layout

On employee mobile conversation screen:

Message header stays at top.

Message list scrolls in the middle.

Reply composer stays fixed above bottom navigation.

Bottom nav stays at the bottom.

Structure should behave like this:

Header

Scrollable message list

Sticky reply composer

Bottom nav

Suggested implementation

Wrap the message page like this:

Main page container:

height: 100dvh;
display: flex;
flex-direction: column;
overflow: hidden;

Header:

flex-shrink: 0;

Message list:

flex: 1;
overflow-y: auto;
padding-bottom: 16px;

Reply composer:

flex-shrink: 0;
position: sticky;
bottom: calc(72px + env(safe-area-inset-bottom));
z-index: 40;
background: white;

Bottom nav:

position: fixed;
bottom: 0;
height: 72px;

Alternative if sticky is unreliable:

Use fixed composer:

position: fixed;
left: 0;
right: 0;
bottom: calc(72px + env(safe-area-inset-bottom));
z-index: 40;
background: white;

Then add padding-bottom to message list:

padding-bottom: calc(140px + env(safe-area-inset-bottom));

Composer row requirements

The composer row should always show:

Attach image button on the left

Text box in the middle

Send button on the right

The send button must never be pushed off-screen.

Use:

display: flex;
align-items: center;
gap: 10px;

Attach button:

flex-shrink: 0;

Text input:

flex: 1;
min-width: 0;
max-height: 120px;
overflow-y: auto;

Send button:

flex-shrink: 0;
