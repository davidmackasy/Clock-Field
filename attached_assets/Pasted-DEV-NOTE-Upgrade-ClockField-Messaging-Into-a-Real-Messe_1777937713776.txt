DEV NOTE: Upgrade ClockField Messaging Into a Real Messenger-Style Communication System

Project: ClockField
Area: Admin Messages, Employee App, Client Portal
Priority: High
Goal: Turn Messages into a full communication hub where admins, employees, management users, and clients can start conversations, reply, send photos, and tag messages by purpose.

Very important

Do not delete, break, rebuild, or rename unrelated features.

Do not touch:

Stripe

Subscription/paywall logic

Authentication

Payroll

Attendance

Scheduling

Worklogs

Training Hub

Hiring package

Client reports

Public report links

Existing employee records

Existing client records

Existing uploaded files

Existing request/report history

Only work on the messaging experience, employee/client messaging entry points, and safe message/photo submission flow.

Use additive changes only.

Do not remove old report/request functionality. Keep old routes/components working unless they are safely redirected to the new messaging composer.

Current issue

The current admin messaging UI looks clean, but it has missing functionality.

Problems:

There is no clear way to start a new message.

Admin cannot choose who to message.

Admin cannot select between client, employee, or management/team member.

Employee app still feels like reports are separate from messaging.

Client portal feels too basic and does not have a strong app-style action button.

Clients cannot easily take photos and send an issue directly to admin.

The experience should feel like a modern messenger, not a basic form.

Reference direction

Use the Workiz-style messaging example as the UX direction:

Left side conversation list

Simple action buttons

Professional app-like interaction

Do not copy branding. Use ClockField branding and current UI system.

Instead of separating “Reports,” “Requests,” and “Messages” into disconnected flows, use message tags.

Security Requirements

Messages must be scoped to the correct business.

Admin can only see messages for their own business.

Employee can only see their own conversations.

Client can only see their own conversations.

One client must never see another client’s messages.

One employee must never see another employee’s private messages.

Client should not message employees directly unless approved later.

Employee should not message clients directly unless approved later.

Management visibility must follow existing permissions.

Do not expose internal notes to clients.

Do not expose private employee data to clients.
