Scope
Only update Training Hub (employee + quiz logic).

Add 15-Second Minimum Time Gate per Module

Goal
Employee must spend at least 15 seconds on a module before they can mark it complete.

Behavior

When a module opens:
Start a timer (per module, per employee)
Disable “Mark Complete” button initially
Button shows: “Read or listen for 15s to continue”
After 15 seconds:
Enable button
Button turns active (blue)
Text changes to: “Mark Complete”

UI

Show a small timer indicator:
“0:15” countdown
or progress bar filling
Mobile (important):
Keep timer inside the sticky bottom bar
Do not block navigation buttons

Edge Cases

If user switches modules:
Reset timer for new module
If user refreshes:
Resume timer if possible using local state
If module already completed:
Do not apply timer again

Implementation

Frontend:

Track moduleStartTime
Compute elapsed time
Enable button when elapsed >= 15 seconds

Backend:

On completion request:
Optionally validate elapsed time (recommended for security)
Reject completion if < 15 seconds with JSON error
Optional: Auto-complete when audio finishes

If using text-to-audio:

If audio duration > 15s:
Enable complete button when audio reaches 15s mark
Do not auto-complete
User must still click “Mark Complete”
