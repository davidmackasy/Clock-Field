User fills:
Page Type
Project / Location
Optional title
Then taps Create Page
Result:
“Failed to create page”

This must be fixed now without changing anything else that is already working.

Scope only:
Fix page creation in Field Notes
Fix only the new page creation flow
Do not touch attendance
Do not touch clock in / clock out
Do not touch payroll

Do not touch authentication

Main goal:
Make Create New Page work reliably from the modal and open the newly created page correctly.

What to investigate first:

Frontend payload
Check exactly what the modal is sending on submit.
Verify:
pageType
projectId or locationId
title
status/default flags
createdBy
organization/company reference
Any required fields missing from the request body
Backend validation
Check the create page endpoint schema.
Likely issue:
frontend is sending one shape
backend expects a different shape
Possible examples:
pageType vs type
projectId missing or null handling broken
“No specific project” not supported properly
title optional in UI but required in backend
enum mismatch for page type like “Maintenance” vs “maintenance”
Database insert
Check whether the record is failing at DB level.
Look for:
non-null constraint failure
foreign key failure
enum mismatch
missing default value
organization/company ID not being attached
slug/publicId generation failure
createdBy required but missing
Error handling
Right now the UI only shows “Failed to create page”
Return the actual server-safe reason in logs and map user-facing message better.
Examples:
Unable to create page. Check required fields and try again.
Unable to create page for this project.
Page type is invalid.
Do not expose raw stack traces to users.

Likely root causes to test:

“No specific project” selection is sending a placeholder string instead of null
If backend expects null and gets “no-specific-project” or empty string, insert may fail.
Page Type enum mismatch
UI shows “Maintenance”
Backend may expect lowercase enum:
maintenance
walkthrough_note
progress_recap
inspection
site_visit
Map UI values to backend-safe enums before submit.
Optional title problem
UI says optional, backend may require title.
If blank, auto-generate a safe default title.
Examples:
Maintenance Page
Untitled Page
Site Visit Page
Do not allow create to fail only because title is blank if UI says optional.
Missing company/business context
If pages belong to a business/org/project, make sure the create route attaches the current tenant/business ID exactly like the rest of Field Notes records.
