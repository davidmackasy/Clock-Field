Dev Note: Fix “Failed to Load Learner Data” in Training Hub Certificate / Quiz Modal

Goal

Fix the Training Hub learner detail modal so clicking a learner from Public Link Learners or Cohort Learners properly loads:

Overview

Quiz Results

Certificate

Activity

Right now, the modal opens, but the content says:

Failed to load learner data.

This must be fixed without breaking or affecting anything else currently working in ClockField.

Do not rebuild the Training Hub.
Do not change the course assignment system.
Do not change public link completion logic.
Do not change course progress calculation unless the bug is directly connected to the learner detail fetch.

Issue Seen

From the screenshot:

The admin clicks a learner under Public Link Learners.

The modal opens correctly.

The learner name and course title show.

The tabs show:

Overview

Quiz Results

Certificate

But the body fails with:

Failed to load learner data.

The learner row still has useful data showing outside the modal:

Name: me

Email: david@gmail.com

Status: Failed

Progress: 100%

Modules: 2/2

Quiz: 0%

Last activity: 23d ago

This means the list data is loading, but the detail endpoint or modal fetch is failing.

Likely Causes

Check these first:

The frontend is calling the wrong learner detail endpoint.
Public link learners may not have the same ID structure as assigned employees.
The modal may be sending employeeId when it should send publicLearnerId, enrollmentId, attemptId, or assignmentId.
Failed learners may not have a certificate record, so the certificate tab might crash the whole modal.
The backend may only support completed or passed learners, not failed learners.
The API may be returning 404 because this learner came from a public link instead of a logged-in employee account.
The query may require courseId + learnerId, but the frontend is only sending learnerId.

Required Fix

Make the Learner Detail Modal Support Both Learner Types

The modal must support:

Logged-in cleaner training records

Assigned employee training records

Public link learner records

Use a normalized payload.

Frontend should pass:

courseId

businessId

learnerType: employee | public

employeeId, only when learner is a real employee

publicLearnerId, only when learner came from public link

enrollmentId, if available

latestAttemptId, if available

Do not assume every learner has employeeId.

Create One Safe Backend Resolver

Add a backend helper like:

resolveTrainingLearnerDetail(params)

It should safely detect:

Is this a logged-in employee?

Is this a public link learner?

Is this a training enrollment?

Does this learner have quiz attempts?

Does this learner have certificate eligibility?

Return a clean response even if some records are missing.

Do not throw a full failure just because the certificate does not exist.

Modal Must Not Fail Fully If Certificate Is Missing

If learner failed:

Certificate tab should show:

Certificate not available because this learner has not passed the course yet.

Do not show “Failed to load learner data.”

If learner has not started:

Show:

No quiz attempt has been submitted yet.

If learner passed but certificate is missing:

Show:

Certificate is ready to generate.

Button:

Generate Certificate

Backend Endpoint Requirement

Add or fix endpoint:

GET /api/training/courses/:courseId/learners/:learnerId/detail

Support query params:

learnerType=employee|public

enrollmentId=

attemptId=

The response should always return a stable shape:

{
learner: {
id,
type,
name,
email,

},

id,

moduleCount
},
progress: {
status,

},

status,
score,

},

eligible,

certificateId,
downloadUrl,
reasonUnavailable
}
}
