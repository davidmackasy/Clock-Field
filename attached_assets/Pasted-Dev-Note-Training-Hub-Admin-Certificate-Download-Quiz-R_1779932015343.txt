Dev Note: Training Hub Admin Certificate Download + Quiz Review Upgrade

Goal

Improve the ClockField Training Hub so admins can view, download, print, and share training certificates for employees who completed and passed a course.

Admins must also be able to review failed attempts and see which questions were answered wrong, without breaking or affecting anything currently working in the Training Hub, cleaner training flow, public training link, course completion logic, assignments, reminders, or existing progress tracking.

Do not change or remove any current working feature.

Core Problem

Right now, when a cleaner completes a course and reaches 100%, the system shows the completion status, but the admin does not have a clear way to:

Download the employee’s certificate

Print the certificate

Re-send the certificate to the employee

Send the certificate to a client as proof of training

Open the completed course and review quiz performance

See failed questions when an employee does not pass

This needs to be added directly inside the existing Training Hub experience.

Backend Requirements

Add or update endpoints safely.

Suggested endpoints:

GET /api/training/courses/:courseId/learners/:employeeId/completion

Returns learner completion details, certificate status, quiz attempts, modules, score, and activity.

GET /api/training/certificates/:certificateId

Returns certificate metadata.

POST /api/training/certificates/generate

Generates certificate only if employee passed.

GET /api/training/certificates/:certificateId/download

Downloads PDF.

POST /api/training/certificates/:certificateId/regenerate

Admin-only certificate regeneration.

GET /api/training/attempts/:attemptId/review

Returns quiz answers, wrong answers, correct answers, and explanations.

Do not change existing assignment, reminder, or progress endpoints unless required.

Data Rules

A certificate can only be generated when:

Course is completed

All required modules are completed

Final score meets or exceeds passing score

Attempt has passed status

Employee or learner identity exists

Do not allow certificate generation for:

Failed attempts

Incomplete courses

Deleted courses

Invalid public link sessions

Unassigned learner unless public link enrollment allows it

Error Handling

Show clean errors.

Examples:

Do not use harsh red full-screen errors.

Do not expose raw backend errors.

Important Safety Instruction

Do not break or affect anything currently working in ClockField.

Do not rebuild the Training Hub.

Do not remove existing progress tracking.

Do not change current assignment logic.

Do not change reminder logic unless needed for certificate email.

Do not change public link enrollment logic.

Do not change course publishing/unpublishing logic.

Only add the certificate download, certificate preview, quiz attempt review, and learner detail modal around the existing completed and failed training records.

Expected Final Result

When a cleaner passes training, the admin can click the learner record, view the completion details, download a professional branded certificate, print it, or send it to a client.

When a cleaner fails, the admin can click the learner record and clearly see what questions were missed, what the correct answers were, and whether the cleaner can retry.

This makes the Training Hub more useful for compliance, client submissions, onboarding proof, and employee coaching.
