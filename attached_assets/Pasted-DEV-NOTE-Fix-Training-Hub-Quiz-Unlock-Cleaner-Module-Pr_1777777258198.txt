Fix Final Quiz Unlock Logic

Issue:
Final quiz says:

“Final quiz locked. Complete all modules to unlock quiz.”

But all modules are already marked complete.

Fix:
Update quiz unlock logic so it checks real module completion correctly.

Quiz should unlock when:

All required modules in the course are completed by the current learner.

Current learner can be:

logged-in employee
public learner from shared link

Check these carefully:

course_id matches
module_id matches
employee_id matches when logged in
public_learner_id matches when public link
only required modules count toward unlock
completed status is saved properly
frontend refreshes progress after marking module complete

Required logic:

totalRequiredModules = all course modules where is_required = true

completedRequiredModules = completed modules for this learner where:
course_id matches
module_id is in required modules
status = completed

If completedRequiredModules >= totalRequiredModules:
unlock quiz

Also handle:
If all modules are required by default, count all modules.
If course has zero required modules, treat all modules as required.
