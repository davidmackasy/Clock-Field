Goal:
When a cleaner starts a session and sees a Priority Clean Required alert, they should be able to tap that priority card and turn it into a proper Work Log area automatically.
What should happen:


Cleaner taps the Priority Clean card.


A new work area is created automatically from that priority issue.


The admin issue photos become the before photos for that new work area.


The title/area name is auto-filled as a priority work section.


Cleaner then only needs to add after photos and optional notes.


Cleaner should be able to add notes by typing or by voice-to-text.


When submitted, the public client link should show the priority work section at the top, then continue the rest of the report as normal.
