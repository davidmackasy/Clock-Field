DEV NOTE: Add Scheduled Daily Field Notes Under Work Log

Project: Clockfield
Feature name: Scheduled Daily Field Notes
Placement: Work Log → Field Notes → Scheduled Field Notes

Main goal:
Build a new Scheduled Daily Field Notes system that works like the current Field Notes workflow, but with admin-created photo steps for each location. Cleaners must follow the required photo checklist before clocking out.

Do not break or affect anything currently working.

Do not change the existing Field Notes system.

Do not change the current Work Log system.

Do not change the current clock-in, clock-out, attendance, payroll, reports, auth, Stripe, or existing public Field Note flow.

This is a new feature that should reuse the Field Notes concept, but it must be separate from regular Field Notes.

Ask for approval before touching anything outside this feature.

1. Feature Concept

We already have Field Notes for site visits, walkthroughs, maintenance, and general notes.

Now we need a new version called:

Scheduled Daily Field Notes

This is for daily cleaning proof.

The admin creates a location-based photo checklist.

Example:

Location: ABC Restaurant
Scheduled Field Note: Daily Closing Cleaning Photos
Assigned Cleaner: Mary
Frequency: Daily
Required before clock-out: Yes

The admin uploads reference photos and names each photo step.

The cleaner does not need to type anything.

The cleaner does not need to write notes.

The cleaner only follows the steps and takes photos.

Voice recording can stay similar to Field Notes if the current Field Note system already supports it, but do not force extra typing.

7. Required Before Clock-Out

If a Scheduled Field Note is marked as Required before clock-out, the cleaner should not be able to clock out until it is completed.

When cleaner tries to clock out without completing it, show a friendly blocking message:

You still need to complete today’s scheduled cleaning photos before clocking out.

Show button:

Complete Scheduled Field Note

Do not change the clock-out system globally.

Only add this check for cleaners who:

Are clocked in

Are assigned to an active scheduled field note

Have an incomplete required scheduled field note for that location and date

Important:

Do not affect cleaners who do not have a scheduled field note.

Do not affect locations without scheduled field notes.

Do not affect existing clock-in/out logic beyond this required validation.

8. Completion Rules

20. Edge Cases

Handle these safely:

Cleaner loses internet

Save draft locally if possible.

Allow retry upload when connection returns.

Cleaner accidentally closes page

When they return, continue from the last incomplete step.

Cleaner clocks in at wrong location

Only show scheduled field notes for the location they are clocked into.

Cleaner has multiple scheduled field notes

Show them clearly as separate cards.

Admin changes template during active submission

Do not change the active submission already in progress.

Apply template changes to future submissions only.

Cleaner needs to retake a photo before final completion

Allow retake before they submit that step.

After completion, prevent editing unless admin has a controlled reopen option.

Photo upload fails

Show clear retry button.

Do not move to next step until upload succeeds.

Required photos not completed

Clock-out should be blocked only if requiredBeforeClockOut is enabled.

22. Suggested MVP Build Order

Step 1: Database

Add new scheduled field note tables.

Keep data separate from current Field Notes.

Step 2: Admin template builder

Allow admin to create a template, add sections, add steps, upload reference images, and assign to location/cleaner.

Step 3: Cleaner mobile flow

Show assigned scheduled field note when cleaner is clocked in.

Build step-by-step photo capture flow.

Save photos to the correct step.

Step 4: Clock-out validation

If requiredBeforeClockOut is enabled and today’s scheduled field note is incomplete, block clock-out and send cleaner to complete it.

Step 5: Admin submission review

Show submissions grouped by location, cleaner, and date.

Allow admin to open each day and review all submitted photos.

Step 6: Work Log connection

Attach completed scheduled field note submission to the daily work log.

Step 7: Public report

Generate public scheduled field note report with intro, sections, submitted photos, timestamps, and outro.

Step 8: Testing

Test with one location, one cleaner, and one 10-step checklist before testing 100+ photos.
