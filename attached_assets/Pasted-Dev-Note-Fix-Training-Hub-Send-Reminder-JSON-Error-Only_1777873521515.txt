Dev Note: Fix Training Hub “Send Reminder” JSON Error Only

Issue

When clicking Send Reminder in the Training Hub course detail page, the request fails with this error:

Failed to execute 'json' on 'Response': Unexpected token '<', "<!DOCTYPE "... is not valid JSON

This means the frontend is calling response.json(), but the server is returning HTML instead of JSON.

Most likely causes:

The reminder API route does not exist

The route path is incorrect

The request is being redirected to an HTML page

The server returns an HTML error page instead of JSON

The frontend is not handling non-JSON responses safely

Backend must always return JSON

The reminder API must always return JSON, including error cases.

Success response example:

{
"success": true,
"message": "Reminder emails sent successfully.",
"sent": 3,
"failed": 0
}

Partial failure response example:

{
"success": true,
"message": "Reminder sent to 2 employees. 1 email failed.",
"sent": 2,
"failed": 1,
"errors": [
{
"employeeId": "employee_id_here",
"reason": "Missing employee email"
}
]
}

Error response example:

{
"success": false,
"message": "Unable to send reminder emails."
}

Important:

Never return HTML from this API route.

Never use res.redirect() from this API route.

Never allow the app shell/index.html to be returned for this endpoint.

Frontend must safely parse response

Update the Send Reminder fetch handler so it does not blindly call response.json().

Use content-type checking first.

Example safe pattern:

const response = await fetch(reminderUrl, {
method: "POST",
headers: {
"Content-Type": "application/json",
},
body: JSON.stringify({ courseId }),
});

const contentType = response.headers.get("content-type") || "";

let data;

if (contentType.includes("application/json")) {
data = await response.json();
} else {
const text = await response.text();
throw new Error(
text.includes("<!DOCTYPE")
? "Reminder endpoint returned HTML instead of JSON. Check the API route path."
: text || "Unexpected server response while sending reminder."
);
}

if (!response.ok || data.success === false) {
throw new Error(data.message || "Failed to send reminder.");
}

Then show the success message from the API.

The backend reminder logic should:

Find the course by courseId

Find assigned employees

Send reminder email only to those incomplete employees

Skip employees with no email

Do not send to employees who already completed the course

Do not send to unassigned employees

Do not create duplicate assignments
