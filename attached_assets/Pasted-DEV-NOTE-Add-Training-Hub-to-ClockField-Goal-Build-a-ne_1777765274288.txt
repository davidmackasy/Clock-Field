DEV NOTE: Add Training Hub to ClockField

Goal:
Build a new Training Hub feature inside ClockField.

This feature allows business admins to create training courses for employees using YouTube unlisted videos, text lessons, slides/images, modules, completion tracking, public course links, and downloadable completion certificates.

Do not break or affect anything currently working.
Do not change existing auth, employee app, admin app, payroll, worklogs, field notes, reports, publications, agreements, Stripe, or existing navigation unless required for this new Training Hub feature.
Ask for approval before touching anything outside this feature.

Feature name:
Training Hub

Main users:
Admin / Business Owner
Employee
Public learner through shared link

Core concept:
Admins can create a course.
Each course can have one or more modules.
Each module can include:

YouTube unlisted video embed
Text lesson
Steps/instructions
Images or slide-style content
Optional quiz/checklist
Completion button

Employees can watch/read modules, mark them complete, and receive a certificate after finishing the course.

Admin can see which employees completed which courses.

Public course links:
Admins should be able to copy a public link for a course and send it to a new hire or employee who does not use the employee app.

Example:
Admin creates “How to Mop Properly”
Course has 5 modules
Admin copies course link
Employee opens the link
Employee watches the training
Employee enters name/email if not logged in
ClockField records completion
Admin can see completion inside Training Hub

YouTube video behavior:
Admin pastes a YouTube unlisted link.
System converts it to an embedded player.
Video shows at the top of the module page.
Do not store or upload video files to ClockField.
Only store the YouTube URL and embed ID.
Support normal YouTube links and youtu.be links.

Permissions

Admin:
Full create/edit/delete/publish/assign access for their business only.

Employee:
Can only see courses assigned to them or available to all employees in their business.

Public learner:
Can only access the course through a valid public link.

Security Requirements

Do not expose private business data on public links.
Public course page should only show:
Company name/logo
Course content
Completion form
Certificate after completion

Validate all YouTube URLs.
Do not allow scripts or unsafe embeds.
Use sanitized rich text for lesson content.

Do not allow one business to access another business’s courses.

Public URL format:
clockfield.com/training/public/[coursePublicId]

Employee URL:
clockfield.com/employee/training

Admin URL:
clockfield.com/admin/training

Important Build Rules

Do not break or affect anything else.
Do not change existing employee profile behavior except adding Training Hub access.
Do not change payroll, schedules, field notes, worklogs, reports, publications, agreements, or auth.
Do not change existing database records outside this new feature.
Use new tables for Training Hub.
Keep all changes isolated.
Make sure mobile works properly before marking complete.

Final Expected Result

Admin can create a professional training course with YouTube unlisted videos, text, slides, and modules.

Employee can complete assigned training from their account.

Admin can send a public course link to new hires.

Admin can track who completed each course.

Employees can download a certificate after completion.

The full feature should feel professional, mobile-friendly, and similar to a simple Udemy-style internal training system for cleaning/service companies.
