DEV NOTE: Add Professional Shareable Proposals & Quotes Feature
Project: Clockfield
Area: Admin Panel
Recommended Feature Name: Proposals & Quotes
Goal: Let admins create professional branded proposals/quotations, share them by link or email, allow clients to view, print, download PDF, accept, reject, or mark “thinking about it,” and let admins track every response inside Clockfield.
Critical instruction
Do not break, remove, rename, or change anything that already works.
Do not change the existing quote request form unless this new feature is safely connected beside it.
Do not remove the current quote form.
Do not change Field Notes.

Feature summary
Add a professional proposal and quotation feature where an admin can generate a branded quote, send it to a lead or client, and track what happens after the client opens it.
The proposal must be:
Shareable by public link
Sendable by email
Printable
Downloadable as PDF
Viewable like a real paper proposal
Acceptable from the public link
Rejectable from the public link
Trackable inside the admin app
This should feel like the quote/proposal tools used by professional cleaning service businesses.

Proposals & Quotes

Pricing calculation rules


If using hourly calculation:
Daily price = hourly rate × hours per visit × number of cleaners
Weekly price = daily price × visits per week
Monthly price = weekly price × 4.33
Tax = subtotal × tax rate
Total = subtotal + tax
Admin must be able to manually override subtotal or final price.
Cleaning quotes often need custom pricing.
Do not lock admin into one calculation method.
