Task
Convert the admin mobile UI into a native-app style navigation experience without affecting desktop layout or breaking any current functionality.

Main instruction
Do not redesign the desktop web app.
Do not change desktop sidebar behavior.
Do not touch auth, page logic, API logic, data loading, schedule logic, payroll logic, attendance logic, or anything else already working.

Main goal

Important

Technical implementation guidance

This shell should handle:

B. Keep desktop shell separate
Do not modify existing desktop sidebar structure beyond responsive show/hide behavior.

C. Route-aware active tab
Bottom nav must highlight based on current route.

D. More menu
If using More tab, make it a bottom sheet or modal menu.

Use responsive classes/logic so:

mobile bottom nav shows only on small screens

F. Keep current pages mounted normally
