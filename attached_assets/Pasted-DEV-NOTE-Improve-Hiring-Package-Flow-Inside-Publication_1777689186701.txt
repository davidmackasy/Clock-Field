DEV NOTE: Improve Hiring Package Flow Inside Publications Only

Goal:
Improve the Hiring Package section inside Publications so new employees must read and accept every company policy before they can complete the rest of the hiring package, upload required documents, sign, and submit.

Do not break or affect anything currently working.
Do not move Hiring Package outside Publications.
Do not add Hiring Package to the main menu or hamburger menu.
Do not change Agreements, Proposals, Publications, Forms, Field Notes, Stripe, Auth, or any unrelated flow.
Only improve Publications > Hiring Package.
Ask for approval before touching anything outside this scope.

Current location must remain:

Publications
Publication
Proposal
Agreement
Hiring Package

Hiring Package must stay inside Publications only.

Main Hiring Package Flow

Admin creates and sends a Hiring Package public link to a new employee.

Employee opens the public link and must complete the hiring package in this order:

Step 1: Review and accept each policy
Step 2: Fill personal information
Step 3: Fill emergency contact information
Step 4: Fill optional medical information
Step 5: Upload required documents
Step 6: Final acknowledgement and signature
Step 7: Submit application
Step 8: See application review status

The employee should not be able to skip ahead.

They must accept each policy before the next one unlocks.

Policy Acceptance Flow

Inside the public link, show the policies as a locked step-by-step checklist.

Example:

Rules of Conduct / Conditions of Employment
Status: Not Started
Code of Ethics
Status: Locked
Dress Code and Personal Hygiene Policy
Status: Locked
Safety Boots Reimbursement Policy
Status: Locked
Substance Abuse Policy / Suspicion of Impairment
Status: Locked
Emergency Contact and Medical Information Notice
Status: Locked

When employee opens policy 1, they must read it and click:

I have read, understood, and agree to this policy.

After clicking accept, policy 2 unlocks.

Repeat this process for every policy.

Do not allow the employee to continue to personal information until every required policy has been accepted.
