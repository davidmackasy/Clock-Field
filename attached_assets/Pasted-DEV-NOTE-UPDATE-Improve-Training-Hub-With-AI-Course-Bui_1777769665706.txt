Not every module needs a video.

If no video is added:
Show module thumbnail/image at the top.

If video is added:
Show embedded video at the top.
Use clean video container.
Do not make it feel like the user left ClockField.

YouTube Thumbnail and Link Handling

When admin pastes a YouTube unlisted link:

Extract video ID.
Save embed URL.
Fetch or generate YouTube thumbnail.
Use thumbnail as course/module image if admin has not uploaded a custom thumbnail.

Important:
Do not show the raw YouTube link on the public course page.
Do not display “Watch on YouTube” buttons.
Embed video inside ClockField.
Disable unnecessary YouTube branding as much as allowed by YouTube embed settings.

Use embed URL format with safe parameters:
rel=0
modestbranding=1
playsinline=1

Do not allow unsafe iframe code from users.
Only allow pasted YouTube URLs.
