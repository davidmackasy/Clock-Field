Upgrade the Clockfield Forms / Quote Requests feature so cleaning businesses can collect better quote information, respond to leads properly, and generate useful estimates for residential and commercial jobs.

This must be implemented as an isolated upgrade to the Forms / Quote Requests system only.

Do not break or affect anything else.

Do not change existing authentication.
Do not change existing subscriptions.
Do not change existing worklogs.
Do not change field notes.
Do not change payroll.
Do not change incident reports.
Do not change existing client reports.
Do not remove any current form submission data.
Do not rename existing routes unless required for this feature.
Do not delete existing fields.
Do not change working form embed behavior.
Do not remove the “Created using Clockfield” embedded branding.
If anything outside this feature needs to be changed, ask first.

1. Current Problems

The current quote form is too basic.

It collects:

Contact information
Service address
Basic service details
Square footage
Bedrooms
Bathrooms
Preferred date
Preferred time

This is not enough to create a proper cleaning quote.

Residential and commercial jobs need different questions.

The submission page is also too limited.

Current submission issue:

Admin receives the submission, but the submission mainly shows basic contact details.
Reply / respond actions do not work properly.
There is no proper flow to generate an estimate from the submission.
There is no proper residential estimator.
Commercial estimator is not giving a clear estimated charge result.
2. Required Final Behavior

When a customer fills out a quote form:

They select Residential or Commercial.
The form changes based on what they select.
The customer only sees questions that match their service type.
The admin receives a detailed submission.
The admin can respond to the customer by email.
The admin can send the submission into the estimator.
The estimator can generate a suggested quote amount.
The estimate result can be used to create/send a cleaning quote.
