10. Backend Completion Check Must Match Photo Task Records
Check the complete checklist endpoint.
It should count required photo tasks from the same template/submission assignment being used in capture.
Example concept:
const requiredTasks = await db.photoTasks.findMany({  where: {    templateId: submission.templateId,    isRequired: true,  },});const completed = await db.photoSubmissions.findMany({  where: {    submissionId,    photoTaskId: { in: requiredTasks.map(t => t.id) },    submittedImageUrl: { not: null },  },});
Then:
if (completed.length < requiredTasks.length) {  return res.status(400).json({    message: "Not all required steps are complete",    missing: requiredTasks.length - completed.length,  });}
Important:

Do not check sectionId only.
Do not check mainStepId only.
The completion check must use photoTaskId.
