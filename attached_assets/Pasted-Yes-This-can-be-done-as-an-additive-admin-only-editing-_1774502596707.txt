GOAL

Add an admin-only ability to edit a submitted cleaner workload entry after it has been submitted, so the admin can improve the final report before generating or sharing the public report link.

This means:
the cleaner submits work as normal,
the submission becomes visible in workload as normal,
the admin opens that submitted entry,
the admin can click Edit,
the admin can update text and selected media for the final report,
the admin can save those edits,
the final generated public report uses the admin-reviewed version.

This is an admin review and edit layer.
It is not a replacement for cleaner submission.

Cleaner submission remains the original source submission.
Admin gets a post-submission editing layer for report preparation.

That means:
cleaner submits once
admin can refine before client-facing output
client sees the admin-approved final version

This is the correct behavior.
