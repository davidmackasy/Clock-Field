the API route does not exist and returns an HTML 404 page

the API route crashes and returns an HTML error page

the request is being redirected to a login page or fallback HTML page

the backend returns text/html instead of application/json

Part 1: frontend submission safety
Wherever Add Client and Add Location forms submit, update fetch handling so it does not blindly call response.json().

Use this pattern:

submit request

inspect response.headers.get('content-type')

if content-type includes application/json, parse json

otherwise read response.text() and throw safe error

show user-friendly toast

log raw response in dev only

Expected safe pattern:

const response = await fetch('/api/clients', {
method: 'POST',
headers: { 'Content-Type': 'application/json' },
body: JSON.stringify(payload),
credentials: 'include',
});

const contentType = response.headers.get('content-type') || '';

let data: any = null;

if (contentType.includes('application/json')) {
data = await response.json();
} else {
const rawText = await response.text();
console.error('Non-JSON response from /api/clients:', rawText);
throw new Error('Server returned an unexpected response. Please check API route.');
}

if (!response.ok) {
throw new Error(data?.message || 'Failed to create client');
}

Do the same for locations.
