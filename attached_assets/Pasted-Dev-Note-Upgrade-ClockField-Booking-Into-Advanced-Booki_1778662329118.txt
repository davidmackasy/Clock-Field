Dev Note: Upgrade ClockField Booking Into Advanced Booking → Estimate → Quote → Client Approval Flow

Goal

Upgrade the current ClockField booking system so service businesses can collect complete booking details, review bookings in a calendar, generate estimates from booking information, create/send quotes to clients, receive client approval, and then confirm the booking.

This must be done without breaking, changing, deleting, renaming, or affecting anything currently working in ClockField.

Do not touch:

Existing Schedule logic

Existing Attendance

Existing Clock In / Clock Out

Existing Employees

Existing Clients

Existing Forms

Existing Work Log

Existing Field Notes

Existing Reports

Existing Payroll

Existing Training Hub

Existing Publications

Existing Settings

Existing public report links

Existing estimate system unless only connecting to it safely

This is an upgrade to Booking only.

Core Concept

Booking should become a full workflow:

Client submits booking request
Admin reviews booking
Admin gets AI estimate from booking details
Admin creates quote
Admin sends quote link to client
Client accepts or declines quote
ClockField notifies admin
Booking status updates
Admin confirms booking
Booking appears clearly on booking calendar
Later, admin can create job/work from the approved booking if needed

Important Rule

A submitted booking is not automatically a confirmed job.

A submitted booking is a request.

Admin must review it, estimate it, send quote, and confirm it.

Part 8: Confirm Booking

Booking status becomes Confirmed Booking.

Create new client using existing client flow

Create job, if Jobs feature exists

Add internal notes

Add scheduled date/time

Assign worker later, if needed

Important:

Do not automatically modify existing Schedule.

Do not automatically assign employee.

Do not automatically create attendance.

Confirmation should only confirm the booking record.

If connecting to Job system later, use Convert to Job action.

Part 9: Convert Booking to Job

If Jobs feature exists or is enabled, add optional button:

Convert to Job

This should happen only after admin action.

Convert flow:

Admin opens accepted/confirmed booking.

Clicks Convert to Job.

Admin selects existing client or creates client through existing client flow.

Admin confirms location.

Admin selects date/time.

Admin assigns worker or team, optional.

Admin adds checklist and photo requirements.

Admin saves job.

Booking status becomes Converted to Job.

Do not touch existing schedule logic.

Do not force this step.

Part 14: Error Handling

Replace vague errors.

Bad:

Could not create quote.

Good:

Quote needs a client name, email, service address, and price before it can be sent.

Bad:

Could not generate estimate.

Good:

Estimate needs service type and property details before it can be generated.

Bad:

Could not send email.

Good:

Quote was created, but the email could not be sent. Please check email settings or copy the quote link manually.
