Main goal
Add an automatic timesheet system that summarizes already-recorded attendance hours for each pay period.

Important rule
Timesheets must not replace attendance.
Attendance remains the source of truth.
Timesheets are only a summary, review, approval, and download layer built from attendance data already in the system.

What this means

employee clock-in and clock-out stays exactly the same

attendance records stay exactly the same

hours calculations stay exactly the same

timesheets are generated from those existing records

employees do not manually type hours

admins can review and approve

employees can review and submit or acknowledge

both sides can download if possible

Product definition
Attendance captures hours.
Timesheets summarize hours.

System behavior summary
At the end of a pay period, or whenever a pay period is viewed:

the system automatically builds a timesheet from attendance records

employee can review it

employee can submit or acknowledge it

admin can review and approve it

both can download it as a simple report

4. DATA SOURCE RULE

All timesheet values must come from actual attendance/time-entry data already stored in the system.

Use:

completed time entries

worked minutes/hours already calculated

overtime if current system already calculates it

attendance flags if useful for summary

Do not use:

scheduled hours only

estimated hours

manual employee input as the main source

payroll totals as the source of attendance hours

If a shift was scheduled but never worked, it should not count as worked time in the timesheet.

11. GENERATION STRATEGY

Recommended safe strategy

When a timesheet is first opened or when a pay period closes:

generate a timesheet snapshot from attendance data for that employee and pay period

If Draft and not yet approved:

optionally allow refresh from attendance if attendance changed

If Approved:

lock snapshot unless admin explicitly regenerates later

Safest MVP

auto-generate timesheet snapshot when viewed

employee submits

admin approves

approved snapshot remains stable

Do not constantly recalculate approved timesheets in the background.
