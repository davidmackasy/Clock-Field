DEV NOTE: Improve Scheduled Field Note Public Link UI
Goal:
Redesign the public scheduled field note link so it looks professional, client-friendly, easy to view, and less internal/admin-focused.
Do not break or affect anything currently working.
Do not change how scheduled field notes are created, submitted, stored, or completed.
Only improve the public link viewing experience.
Current issue:
The public link currently shows too much internal completion data, including:
21 of 21 steps completed
100% progress bar
Total steps
Completed count
Large section blocks for every office
All completed photos shown immediately
Internal-style completion layout
This makes the client page feel busy, boring, and too operational.
Required changes:


Remove internal progress details from the public link


Hide these from the public client view:
“21 of 21 steps completed”
Green 100% progress bar
Total Steps card
Completed card
The large summary stat boxes
The client should not see internal workflow progress.


Keep useful client-facing timing info


Keep:
Date
Location/client/site name
Cleaner or company name if already shown
Started time
Completed time
Move Started time and Completed time into the top header area.
Example layout:
Master Cleaning
Fortune
May 1, 2026
OBG Inc
Completed by: David Mackasy
Started: 11:13 AM
Completed: 11:21 AM


Add a short report introduction


Add a clean intro section under the header.
Example copy:
Daily Proof of Work
This report shows the completed scheduled field note photos for this location. Select an area below to view the photos taken for that section.
Keep it simple and client-friendly.


Replace long office blocks with a thumbnail grid


Instead of showing every office section opened by default, create an Instagram-style area grid.
Each area should show as a photo card.
Example cards:
Main Office
Ryan’s Office
Stacy’s Office
Kitchen
Back Office
Upstairs Office
Each card should use the first photo from that area as the thumbnail.
Grid behavior:
Desktop:
4 cards per row
Tablet:
3 cards per row
Mobile:
2 cards per row, or 1 if screen is too small
Each card should show:
Thumbnail image
Area name
Photo count, example: “8 photos”
Optional completed time range if available
Do not show internal step counts like “8 of 8 completed.”


Add expandable photo sections


When a client clicks an area card:
Expand that area below the grid or open a clean inline drawer.
Show all photos for that area.
Allow the client to collapse it again.
Required behavior:
Only show photos after the area is clicked.
Client can open and close each area.
Keep the page easy to navigate.
Do not force the client to scroll through every photo immediately.
Photo layout inside expanded section:
Large clean grid
Desktop: 4 photos per row
Mobile: 2 photos per row
Each photo should show:
Photo thumbnail
Time taken
Optional label if already available
Clicking a photo should open a larger preview modal.


Remove the old public block layout


Do not show the current large rows like:
Main Office
8 of 8 completed
All tiny photos inside a long horizontal row
Replace this with the new card grid and expandable gallery system.


Add a small Clockfield branding badge


Add a small non-distracting badge in the corner or near the bottom.
Example:
Generated using Clockfield
Keep it subtle. Do not make it look like an ad.


Keep the existing footer


Keep:
Report generated by Master Cleaning
Powered by Clockfield
Proof of Work
Do not remove the existing bottom branding/footer.


Add client support message


Add a small message near the bottom before the footer.
Example:
Questions or concerns?
Please contact the service provider directly if you have any questions about this report.
If there is already a contact button or message option, keep it and style it cleanly.


UI style requirements


Make the public page feel:
Professional
Clean
Modern
Client-facing
Easy to scan
Mobile-friendly
Use:
Rounded photo cards
Soft shadows
Clean spacing
Large thumbnails
Readable labels
No crowded progress bars
No internal admin-style stats


Safety requirements


Do not change:
Scheduled field note creation
Cleaner submission flow
Admin review flow
Image upload logic
Database structure unless required
Existing public link routing
Existing permissions
Existing completed status logic
Existing report generation logic
Only change the public scheduled field note display UI.
Final expected result:
The public link should no longer look like an internal task checklist. It should look like a polished client proof-of-work gallery where the client can quickly see each area, click an area, view its photos, and understand when the work started and finished.
