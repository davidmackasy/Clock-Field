Dev Note: Add Jobsite Walk With AI-Assisted Measurement
Goal:
Add a new Jobsite Walk feature inside Clockfield without breaking or affecting any existing Field Notes, Worklogs, Reports, Proposals, Scheduling, Attendance, Payroll, Auth, Stripe, or client report flows.
Placement:
Add Jobsite Walk under Field Notes as a new walkthrough type.
Do not create a new top-level menu item for now.
Suggested structure:
Field Notes


Regular Field Note


Jobsite Walk


Feature Purpose:
Jobsite Walk should help admins or employees complete bid walkthroughs using photos, AI-assisted measurements, voice notes, and project documentation.
The goal is to let users walk through a jobsite, take photos, detect estimated measurements, save everything into the project photo log, and use the information later for proposals, estimates, and client-facing reports.
Core Workflow:


User opens Field Notes


User selects Jobsite Walk


User creates or selects a project/client


User takes walkthrough photos


AI analyzes each photo


AI detects possible measurements and important site details


User confirms, edits, or corrects AI measurement suggestions


Confirmed measurements are saved with the photo


Photos are stored in the project photo log


User can generate a walkthrough summary


Summary can feed into Proposal Builder or standalone PDF/report


AI-Assisted Measurement Requirements:
The system should support AI-first measurement detection.
AI should attempt to detect:


Room/area type


Approximate length


Approximate width


Approximate square footage


Wall size


Floor area


Window count


Door count


Washroom count


Surface type


Floor condition


Cleaning risks


Special equipment needs


Important:
AI measurements must be treated as estimates until confirmed by the user.
Display wording:
“AI-estimated measurement”
“Needs confirmation”
“Confirmed by user”
Measurement Confirmation:
After AI detects a measurement, the user must be able to:

Add a note to the measurement


Example:
