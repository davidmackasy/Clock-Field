Base formulas

regular_pay = regular_hours × hourly_rate
ot_pay = overtime_hours × overtime_rate
gross_pay = regular_pay + ot_pay

Then:
federal_tax = based on selected mode
provincial_tax = based on selected mode
cpp = based on selected mode
ei = based on selected mode
custom_deductions = sum of active custom deduction rules

total_deductions = federal_tax + provincial_tax + cpp + ei + custom_deductions
net_pay = gross_pay - total_deductions

Round only at display layer to 2 decimals.
