DEV NOTE: Upgrade Supplies Page Into Inventory + Location Expense Management

Project: ClockField
Page: Admin Panel > Supplies
Goal: Upgrade the existing Supplies page into a full supply inventory and expense tracking system for service businesses.

Important instruction:
Do not break, remove, rename, or change any existing working supply request flow.
Do not affect cleaners, admin login, employee pages, schedules, attendance, payroll, clients, work logs, publications, settings, subscription, messages, or super admin.
Only work inside the Supplies module and related supply data models/API routes needed for this feature.
Do not delete existing supply records.
Do not change the current cleaner request concept.
Do not change how cleaners take pictures when they need supplies.
Only extend the system safely.

Main concept

The Supplies page should no longer only show items that locations need.

It should now help an admin answer these questions:

What supplies does the company currently have in inventory?
How many units were purchased?
How much did each unit cost?
How much total inventory value does the company have?
Which location received which supplies?
How much money has each location used in supplies?
Which supplies are running low?
Which supplies are out of stock?
Which cleaner requested a restock?
What was fulfilled from inventory?
What still needs to be purchased?

Example:

The company buys:

Orange Solv
Quantity: 7
Unit price: $29
Total inventory value: $203

Then the admin sends:

2 units to Anchor Construction
1 unit to OakBank Arena
2 units to Karrich Industries Inc

Inventory remaining:

2 units

Expense by location:

Anchor Construction: $58
OakBank Arena: $29
Karrich Industries Inc: $58

The inventory should decrease when supplies are assigned to a location.

The location expense should increase based on the product unit price.

This must work for chemicals, rugs, mops, dispensers, garbage bags, paper products, equipment, or any custom supply category.

Core logic

Add inventory

Input:
Product name
Category
Quantity
Unit price

Process:
Create inventory item.
Set current quantity.
Create inventory purchase record.
Create inventory movement with type purchase.

Formula:
total_cost = quantity × unit_price

Assign inventory to location

Input:
inventory_item_id
location_id
quantity
unit_price from inventory item
optional supply_request_id

Process:
Check inventory exists.
Check current_quantity >= quantity.
Calculate total_expense.
Decrease inventory current_quantity.
Create location_supply_expenses record.
Create inventory_movements record with movement_type assigned_to_location.
Update inventory item status.
If linked supply request:
Update fulfilled quantity.
Update request status.

Formula:
total_expense = quantity × unit_price_at_time

Important:
Use unit_price_at_time for expense records.
Do not make old records change when admin edits current unit price later.

Restock inventory

Input:
inventory_item_id
quantity_added
unit_price
supplier
purchase date

Process:
Increase inventory current_quantity.
Update latest unit_price if admin confirms or if Step 1 keeps it simple, update automatically.
Create inventory purchase record.
Create inventory movement record.
Recalculate status.

Location expense calculation

For each location:

This month spend:
Sum location_supply_expenses.total_expense where assigned_date is inside current month.

All time spend:
Sum all location_supply_expenses.total_expense for that location.

Category spend:
Group by category.

Item spend:
Group by inventory_item_id.

Inventory value calculation

Current inventory value:

For Step 1:
current_quantity × latest unit_price

Example:
2 Orange Solv remaining × $29 = $58 inventory value

Later Step 2 can support weighted average cost or FIFO.
Do not overcomplicate Step 1.
