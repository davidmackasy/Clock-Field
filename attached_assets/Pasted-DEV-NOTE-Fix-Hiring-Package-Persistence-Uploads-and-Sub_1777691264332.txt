DEV NOTE: Fix Hiring Package Persistence, Uploads, and Submission Review

Goal:
Fix the Hiring Package system properly so employee progress, accepted policies, personal information, uploaded documents, and signature are saved permanently. Also add a proper submissions section inside Publications > Hiring Package where admin can review everything submitted.

Do not break or affect anything currently working.
Do not touch Agreements.
Do not touch Proposals.
Do not touch normal Publications.
Do not touch Forms, Field Notes, Auth, Stripe, Payroll, Attendance, or Employee app.
Do not move Hiring Package outside Publications.
Only fix and complete Publications > Hiring Package.

Main problems to fix:

Required document uploads are not working.
Accepted policies are not being saved after refresh.
Employee progress resets back to the first policy after refresh.
Personal information, emergency contacts, medical info, documents, and signature may also not persist.
Admin does not have a proper submitted applications section to review employee submissions.
Upload size may be too small and should be increased safely.

Expected result:
When an employee accepts policies, fills information, uploads files, signs, and submits, everything must save to the backend. If they refresh the page or reopen the same public link, their progress should still be there.

Fix Public Hiring Package Save System

The public hiring package page must not rely only on frontend state.

Everything must save to the backend as the employee completes each step.

Save these fields:

Accepted policies
Current step
Personal information
Emergency contacts
Optional medical information
Uploaded documents
Signature
Final acknowledgement
Submission status
Last saved time

When the employee refreshes the page, reload the saved submission by public token.

Correct behavior:

If employee accepted 3 policies, refresh should show 3 policies accepted.
If employee accepted all policies, refresh should not bring them back to policy 1.
If employee filled personal info, refresh should keep the saved personal info.
If employee uploaded documents, refresh should show uploaded files.
If employee signed, refresh should show signed status or completed status.
If employee submitted, refresh should show review status page.
