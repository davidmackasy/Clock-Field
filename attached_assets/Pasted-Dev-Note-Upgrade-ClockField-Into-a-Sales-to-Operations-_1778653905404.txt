Dev Note: Upgrade ClockField Into a Sales-to-Operations Platform Without Breaking Existing Features
Goal
Upgrade ClockField so it helps small cleaning and service businesses with the full business journey:
Get a client request
Estimate the work
Price the job
Create a proposal
Turn approved work into an active client/job
Track the worker
Collect proof
Send the client one clean report link
This upgrade must improve ClockField without replacing or breaking anything that already works.
Do not rebuild the existing app.
Do not change existing client records.
Do not change existing schedules.
Do not change attendance.
Do not change clock-in or clock-out.
Do not change Field Notes.
Do not change Work Reports.
Do not change public client report links.
Do not change payroll estimator.
Do not change current client management.
This should be added as a new sales-to-operations layer that connects safely to existing ClockField systems.
Main Product Direction
ClockField should become more than a management tool.
New positioning:
ClockField helps cleaning and service businesses get client requests, price jobs, create proposals, manage workers, and prove the work with photos, notes, schedules, and client report links.
Simple product loop:
Client requests a quote.
Business owner reviews the lead.
Business owner does a walkthrough.
ClockField helps estimate time, price, staff, and checklist.
ClockField creates a proposal.
Client accepts.
Admin turns the approved quote into an active client/job.
Cleaner clocks in like normal.
Cleaner uses existing Field Notes or Work Reports.
Admin sends the existing public client report link.
Core Safety Rule
Everything new must be optional.
Existing ClockField users should be able to keep using the app exactly as they do today.
If the business does not use leads, quotes, walkthroughs, or proposals, nothing should change for them.
Use additive development only.
Add new tables.
Add new pages.
Add optional links to existing systems.
Do not delete existing fields.
Do not rename existing fields.
Do not rewrite existing workflows.
Do not force existing records into the new system.
Recommended Feature Flag
Add this behind a feature flag:
enable_sales_operations_flow
When disabled:
ClockField works exactly like it does today.
No new lead, quote, walkthrough, or proposal pages appear.
When enabled:
The new sales-to-operations flow appears in the admin dashboard.
Existing systems remain unchanged.
New Modules To Add
Add these new modules:


Lead Inbox


For new client requests from public forms.


Quote Request Form


A public form that businesses can share to collect client requests.


Walkthrough Assistant


A guided tool for inspecting a job location, taking photos, adding notes, and preparing pricing details.


AI Pricing Assistant


A pricing support tool that helps estimate time, staff, supplies, and price range.


Proposal Builder


A tool that turns a quote into a clean client-facing proposal link.


Convert to Client / Job Setup


A safe action that turns an approved quote into existing ClockField client, location, schedule, checklist, and report setup.
Important:
These modules must connect to existing ClockField features, not replace them.

Module 6: Convert Approved Proposal to Client / Job Setup
Purpose
Make it easy to turn a sold quote into real operations.
This solves:
“How do I go from accepted quote to actual work?”
When proposal is accepted, admin should see:
Convert to Client / Setup Job
Options:
Link to existing client
Create new client using existing client creation flow
Create location using existing location flow
Create checklist
Create service schedule, optional
Create first job/work plan, optional
Assign cleaner, optional
Set required photos
Set report requirements
Important Rule
Do not create clients automatically without admin confirmation.
Do not duplicate existing clients.
Do not change existing client system.
Use existing client creation and location creation flows.
Safe Convert Flow
Step 1: Match Client
System checks if client email, phone, or company already exists.
If match found, admin can link to existing client.
If no match, admin can create new client.
Step 2: Create Location
Use existing location system.
Step 3: Create Service Setup
Create checklist and job details.
Step 4: Optional Schedule
Admin may create a regular schedule if needed.
This should use existing schedule flow.
Do not change schedule logic.
Step 5: Existing Operations Continue
Cleaner clocks in using existing clock-in.
Cleaner uses existing Field Notes or Work Reports.
Admin sends existing public report link.
