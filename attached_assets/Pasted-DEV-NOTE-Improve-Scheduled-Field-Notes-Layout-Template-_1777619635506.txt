DEV NOTE: Improve Scheduled Field Notes Layout, Template Builder, Submissions, Reports, Public Link, Photo Viewing
Project: Clockfield
Feature: Scheduled Field Notes
Area: Admin Work Log → Scheduled Notes
Main goal:
Improve the Scheduled Field Notes system so it is easier to manage, more professional, more organized, and better for long-term daily cleaning records.
Do not break or affect anything currently working.
Do not change regular Field Notes.
Do not change Work Log behavior outside Scheduled Notes.
Do not change clock-in, clock-out, payroll, attendance, clients, reports, auth, Stripe, or existing public Field Notes.
Only improve the Scheduled Field Notes module.
Ask for approval before touching anything outside this feature.
Current issue:
The Scheduled Notes system works, but the layout is too narrow and too vertical.
Templates, assignments, submissions, reports, and public reports are showing too much information in single rows.
This will not work when a location has 50, 100, or 150 required photos.
We need a cleaner grid-based layout that saves space and makes photos easier to review.
