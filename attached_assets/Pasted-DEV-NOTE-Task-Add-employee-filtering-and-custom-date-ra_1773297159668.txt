This task is only to improve the Payroll Estimator filters.

Main goal
The Payroll Estimator currently supports period filtering only.
It needs two additional improvements:

Employee filter
Admin should be able to select one employee and see payroll totals only for that employee

Custom period filter
Admin should be able to select a custom start date and end date and generate the payroll estimate for that exact range

Current issue
Right now payroll is showing totals for all employees combined.
That is useful, but admin also needs to isolate one employee.

Example:
Admin wants to see only David Zulu for This 2 Weeks
or
only Mackasy Xulu for Mar 1 to Mar 14

The Payroll page should support that cleanly.

Place it near the period selector.

Source of truth
Use the existing payroll estimator logic.
Do not create a second payroll calculation path.

The new employee and custom filters must pass into the same shared payroll calculation helper already used by the page.

That helper should receive:

employeeId optional

period preset optional

startDate optional

endDate optional

Example logic
If employeeId is null:
calculate for all employees

If employeeId exists:
calculate only for that employee

If period preset is custom:
use startDate and endDate

If period preset is standard:
use shared date-range helper

Custom range date handling
Use inclusive range logic.
Do not accidentally drop entries on the end date.

Safe rule:

startDate = selected start day at 00:00:00

endDate = selected end day at 23:59:59
or equivalent inclusive logic in your current system
