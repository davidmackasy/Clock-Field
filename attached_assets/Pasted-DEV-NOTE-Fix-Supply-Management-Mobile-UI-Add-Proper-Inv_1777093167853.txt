Project: ClockField
Area: Admin Panel > Supply Management
Related areas: Employee/Cleaner Supply page only
Priority: High
Goal: Fix the Supply Management page so it works properly as an inventory, supply assignment, location expense, and cleaner request system.

Critical instruction:
Do not break or affect anything else in ClockField.

Current problems to fix

Problem 1: Admin Supply page is not mobile friendly

On mobile, the Supply Management page is wider than the screen.
The user has to scroll left and right.
Tabs, cards, filters, and buttons are overflowing.
The page does not fit small phones properly.

Problem 2: Location Expenses has no way to add expenses

The Location Expenses tab only shows empty data.
There is no action to assign inventory to a location.
There is no way to create a location expense from inventory.

Problem 3: “Requests” is being used wrong

The current “Requests” tab is being used like “Add Supply.”
This is confusing.

Admin should have:

Inventory: Products the company owns.
Add Supply / Assign Supply: Move product from inventory to a location.
Location Expenses: Shows what each location has received and how much it cost.
Requests: Only for cleaner requests.

Cleaner requests should only happen when:

Cleaner needs something not already listed.
Cleaner wants to request a new supply.
Cleaner reports that an existing supply is out, low, missing, or needs replacement.

Main concept

Inventory is the company’s stock.

Example:

All Pink
Quantity purchased: 5
Unit price: $29
Total inventory value: $145

When admin assigns 1 All Pink to Olympic Building Centre:

Inventory goes from 5 to 4.
Olympic Building Centre gets 1 All Pink.
Olympic Building Centre supply expense increases by $29.
The employee assigned to that location can now see that product on their supply page.

Do not let admin retype the product again if it already exists in inventory.

When adding supply to a location, admin must select from existing inventory.
