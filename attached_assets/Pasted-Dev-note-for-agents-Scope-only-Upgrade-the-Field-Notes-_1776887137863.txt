Dev note for agents

Scope only:
Upgrade the Field Notes / Documents / Page experience on the notefield page only.
Do not touch attendance.
Do not touch clock in or clock out.
Do not touch payroll.
Do not touch requests.
Do not touch schedules.

Do not touch any other working flow.

Production is active. Do not delete data. Do not change existing field note records. Do not break current public share links. Do not break current AI walkthrough generation.

Goal:
Upgrade the current field notes experience so it feels and behaves closer to the CompanyCam “Pages” and “Walkthrough Note” concept, while keeping our existing Clockfield field note identity, public link flow, AI generation flow, and current report structure. CompanyCam’s official docs show a Pages-based flow where users can create a blank page inside a project, create a page from selected photos, use AI actions like Walkthrough, Summary, Daily Log, and Progress Recap, then share the result as a link or export it as a PDF. Their mobile flow also supports creating a page from the project, adding photos inside the page editor, opening page settings, adding a cover page, and exporting or sharing afterward.

Primary product direction:
Keep the existing “walk and talk” AI field note flow.
Add a second creation path:

Start Walkthrough Note
Create New Page

The final experience should support both:
A. Live AI walkthrough capture with camera + voice + auto-organized notes
B. Manual page creation where users can upload photos, add sections, add descriptions, add to-dos, then export/share as a public field note

Reference behavior from CompanyCam:
CompanyCam supports blank Pages, AI-generated Pages from selected photos, cover pages, page settings, share link, PDF export, and photo detail controls. Pages are positioned as flexible documentation that can include notes, photos, reports, and AI-generated summaries.

Creation flows to support:

Flow 1. Walkthrough Note
User taps Start Walkthrough Note
Camera opens in walkthrough mode
User walks, talks, snaps photos
Existing AI continues to process voice + images
When done, generate an editable page
The generated page must remain fully editable before sharing/export
This matches CompanyCam’s official walkthrough note behavior where the AI combines voice and photos into an editable page that can then be shared or exported as PDF.

Flow 2. Create New Page
User taps Create New Page
Open a blank page editor
Let them:
Add title
Add short intro
Upload photos
Reorder photos
Add short description per photo
Add section headings
Add to-do items
Add manual notes
Add files if needed
Generate AI descriptions for selected photos
Generate AI summary for the page
Share as public link
Export as PDF

This should mirror the idea of CompanyCam Pages, where users can start from a blank page, insert photos, and later share/export it.

Photo handling requirements:
Every uploaded photo inside a page should support:
Caption / short description
Optional AI-generated short description
Optional manual edit after AI fills it
Drag to reorder

Delete from page without deleting the original project asset unless explicitly requested

AI for photo descriptions:
When the user uploads a photo, give them:
Write it myself
Generate with AI

AI output should be short, useful, and professional.
Example style:
“Electrical rough-in visible in framing stage.”
“Window opening prepared and insulation material staged.”
“Basement framing area photographed for progress documentation.”

Do not generate long paragraphs by default.
Use 1 to 2 short lines unless the user expands it.

Research summary for design direction:
CompanyCam’s current official Pages flow supports blank pages, AI page generation from project photos, Walkthrough Note, Progress Recap, cover pages, page settings, share links, and PDF export. Their AI walkthrough flow is designed around walking the site, talking naturally, capturing photos, then generating an editable page for sharing. That is the correct benchmark for this upgrade, but the implementation must stay within Clockfield’s current field-note architecture and must not impact other parts of the app.
