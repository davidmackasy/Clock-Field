Priority 1: Restore rendering for existing Field Note sessions

Main goal

Restore the affected Field Note session page so existing saved notes open correctly again.

Focus areas to inspect

1. Frontend route rendering
   Check the session detail page for a runtime crash.
   A blank white screen usually means the page is crashing during render.

Inspect:
session page component
data fetching hook
tab rendering for Document, Photos, Transcript
new Proposal tab or new quote-related UI added recently
any conditional rendering added in recent Field Notes updates

Most likely issue

A recent Field Notes change introduced a render error on session detail pages when certain data is missing, old, or shaped differently.

2. Backward compatibility with older or existing session records
   Check whether recent schema or UI changes now assume fields that older or existing Field Note sessions do not have.

Examples to check
proposal fields missing
quote output fields missing
new grouped sections missing
new transcript structure missing
new image metadata missing
new pricing fields missing
new proposal status fields missing

Required fix

Any new UI added to the Field Note session page must safely handle missing values.
Do not assume every record has the newest fields.

Use defensive rendering:
if missing, show fallback
if null, skip section safely
if array missing, default to empty array
if proposal data missing, do not crash the whole page

3. API response inspection
   Check the session fetch endpoint used by this page.

Verify:
the session API is still returning data
the returned payload is valid
the frontend is not failing when parsing it
there is no JSON shape mismatch from recent changes

If the API works but the page is blank, the issue is likely a frontend runtime error.
If the API fails, fix only that endpoint path for session loading.

Priority 2: Do not let new quote or proposal UI break normal notes

Recent work added:
quote proposal logic
proposal tab/status logic
pricing display logic
new field note rendering behaviors

Required guardrail

If a session is a normal note or older note and does not have proposal data, the page must still open fully.

Do not block Document, Photos, or Transcript just because Proposal or Quote-related data is missing.

Safe behavior

If proposal exists:

If proposal does not exist:
