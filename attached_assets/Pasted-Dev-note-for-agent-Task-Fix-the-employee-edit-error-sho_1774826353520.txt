Problem

When editing an employee, saving fails with:

500: {"message":"invalid input syntax for type numeric: """}

This strongly points to a numeric field being sent as an empty string instead of null or a real number.

Most likely field
Hourly Rate ($)

In the screenshot, Hourly Rate is blank.
The backend/database numeric column is probably receiving:
""
instead of:
null
or
0
or
a valid numeric value

Root cause to fix

The employee update flow is sending empty string values for numeric fields.
Postgres numeric columns cannot accept an empty string.

Required fix

Make the employee edit/update flow safely normalize numeric inputs before sending to the backend and before writing to the database.

Main rule

For numeric fields in employee edit:

* if the field is blank, send null
* if the field has a value, convert it to a proper number
* never send empty string to a numeric DB column

What to check

1. Frontend form state
   Check the employee edit form values for fields like:

* hourlyRate
* any other numeric employee fields

If input is blank, do not keep it as "" when building the payload.

Required frontend normalization example

* "" -> null
* "25" -> 25
* "25.50" -> 25.5

2. Submit payload builder
   Before calling the update API, sanitize the payload.

Example logic

* trim string inputs
* for numeric fields:

  * if value === "" or value is undefined, convert to null
  * else convert to Number(value)
  * only send valid numbers or null

3. Backend validation/schema
   Also protect this on the server side.
   Do not rely only on frontend cleanup.

On the employee update endpoint:

* if numeric field arrives as ""
* convert it to null before DB update
  or reject it cleanly before query building

Preferred
Normalize server-side too, so the API is safe even if the client sends bad data.

4. Database update query
   Make sure the update query is writing:

* numeric value
  or
* null

Never pass empty string to numeric columns.
